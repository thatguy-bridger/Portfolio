Pill-shaped action button with a hover scale + glow, used for all primary actions (save, publish, add section).

```jsx
<Button variant="primary" size="md" onClick={handlePublish}>Publish site</Button>
```

Variants: `primary` (indigo), `secondary` (purple), `danger` (red), `success` (green), `ghost` (outlined, transparent). Sizes: `sm` `md` `lg`. `disabled` dims and disables hover.
